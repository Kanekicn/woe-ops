Privacy Policy

Last updated: 2026-10-09

WorldofEnglish Ops ("the app") is a personal tool used only by its owner. It is not offered to the public.

What Google data the app accesses

The app requests a single Google OAuth scope, https://www.googleapis.com/auth/drive.file. With it, the app can only see and change the files it creates itself: one Google Sheets spreadsheet (the editorial calendar) and one Google Drive folder (generated images). It cannot read any other file in your Google Drive.

How the data is used and stored

  • Data is read and written only to run the owner's editorial workflow (topics, drafts, publishing logs, reviews).
  • The OAuth token is stored only on the owner's computer, in a file readable by the owner alone.
  • The app has no server. No Google user data is sent to the app developer or to any third party, sold, or used for advertising.
  • The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Deleting your data

Delete the spreadsheet and folder in Google Drive, and revoke the app's access at myaccount.google.com/permissions.
