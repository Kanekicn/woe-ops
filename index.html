WorldofEnglish Ops

WorldofEnglish Ops is a personal, single-user tool that helps its owner run a Xiaohongshu (RED) account about English idioms and word origins.

It runs only on the owner's own computer. It uses Google Sheets to keep an editorial calendar and Google Drive to store the images it generates, and it can only access the spreadsheet and folder that it created itself (Google scope drive.file).

WorldofEnglish Ops 是个人自用的小红书运营工具，只在作者本机运行，只能访问它自己创建的表格和文件夹。
